# Minho Fresh — Practical 2 (Computational Tools for Data Science, MIAA, IPCA)

Revenue report 2025 of the Minho Fresh supermarket chain (synthetic data), as a notebook and as a KNIME workflow.

## Contents

| Path | What it is |
|---|---|
| `data/` | Synthetic data: weekly sales 2023–2025 (`store_sales_pt.csv`, Excel export with `;` and decimal comma; `store_sales.csv`) and the store table (`stores_dup.csv`, `stores.csv`) |
| `notebooks/f2_fixed.ipynb` | The fixed notebook (Exercise 1) |
| `workflows/P2_fixed.knwf` | The repaired KNIME workflow (Exercise 2) |
| `environment.yml` | The conda environment (Exercise 3, step 1) |
| `.github/workflows/check.yml` | Runs the notebook on Ubuntu, Windows and macOS on every push |
